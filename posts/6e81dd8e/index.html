配置第一个反向代理

  1. 点击“Host”，进入Proxy Host，进入Add Proxy Host
  2. 填写以下几点信息：
  • Domain Names: 你的域名 (例如：example.com)
  • Scheme: 选择 http 或 https，取决于你的后端服务。
  • Forward Hostname / IP: 你的后端服务的 IP 地址或域名。
  • Forward Port: 你的后端服务的端口号。
  • Cache Assets: (可选) 启用缓存，提高网站性能。
  • Block Common Exploits: (可选) 启用安全防护。
  • SSL:
    • SSL Certificate: 选择 “Request a new SSL Certificate” (如果还没有证书)。
    • Email Address: 你的邮箱地址，用于 Let’s Encrypt 证书申请。
    • Force SSL: 强制使用 HTTPS。
    • HTTP/2 Support: 启用 HTTP/2，提高网站性能。
      3.点击save

其他坑记录

access list 不生效

现象：你在 Advanced 中写了 location 规则，认证全部失效。
原因：当你写自定义 location 时，主配置的 access_list 不会自动应用进去，因为 Nginx 的访问控制是逐层继承的，而 Advanced 块完全替换了默认配置。

IP 规则与认证规则冲突（Satisfy Any）

现象：设置了密码，但某些 IP 能直接绕过。
原因：如果在 Access List 中同时设置了 IP 规则和认证，且开启了 Satisfy Any（允许任一），则 IP 白名单内的用户无需密码即可访问。
