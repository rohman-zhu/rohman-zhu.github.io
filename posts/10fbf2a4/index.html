替换vCenter证书工具-fixcerts脚本

Posted on 2026-10-01 In VMware , vSphere

概述

本文介绍使用 Fixcerts 脚本（fixcerts_3_2.py）替换 vCenter Server Appliance（VCSA）上的证书。

⚠️ 官方弃用提示：使用本文附带的脚本替换证书的方式已弃用（deprecated）。官方建议改用新的改进版证书管理工具 vCert - Scripted vCenter Expired Certificate Replacement 进行所有证书管理/替换工作流（详见本站文章《VCSA证书替换工具-vCert》）；也可以使用 vCenter 管理界面的 Manage Certificates（管理证书） 菜单检查和替换证书。本文仅作为历史记录与参考。

脚本可替换的证书类型

  • VMCA Root（VMCA 根证书）
  • MACHINE SSL（机器 SSL 证书）
  • **Secure Token Signing (STS)**（安全令牌签名证书）
  • Solution Users（解决方案用户证书）
  • LookupService 或 STS_INTERNAL_SSL_CERT（查找服务证书）
  • data-encipherment（数据加密证书）
  • SMS（过期证书）
  • TRUSTED_ROOTS 存储中的过期证书
  • TRUSTED_ROOTS 存储中的非 CA 证书
  • 更新 vpxd 扩展的 thumbprint（指纹）：eam、rbd、imagebuilder

注意事项

  1. Fixcerts 会将自定义证书替换为 VCSA 自签名证书（即会覆盖企业 CA 签发的自定义证书）；
  2. Fixcerts 不是 vCenter Server 证书管理 UI 或 CLI 的替代品；
  3. 仅支持 VMware vCenter Server Appliance（VCSA），不支持 Windows 版 vCenter Server；
  4. 如果使用 Enhanced Linked Mode（增强链接模式），操作前需对域内所有 vCenter 服务器做离线快照（offline snapshots）。
