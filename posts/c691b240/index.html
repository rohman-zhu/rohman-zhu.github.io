Grafana-JSON数据源处理实例

Posted on 2026-07-25 In default

需求背景

我写了一个JSON数据源，里面是全量的数据，相当于是一张静态表，需要通过Grafana做数据展示，数据源如下：

其中有一个date字段，我想筛选出指定日期的数据，比如2026-01-01至2026-03-01，结果DeepSeek的答复死活都无法测试通过，他还使劲忽悠我。（这里该批评D老师，AI幻觉太严重了，还信誓旦旦地说可以）

错误方案演示 – 来自DeepSeek

【错误方法】在面板的 Transform 选项卡中，点击 + Add transformation，选择 Filter data by values

核心：

  1. Operator：选择 Is lower or equal（小于等于）。
  2. Value：填入 ${__now}。这是Grafana的全局变量，代表“当前时间”。Grafana从 v11 开始已支持在转换中使用变量。

结论：
这个方式是错误的，我的Grafana版本没有 Is lower or equal ;

【错误方法】没有 Is lower or equal ，只有Is Between，设置了也不生效

初始答复是正确的：
“你看到只有 is between，是因为 Grafana 会根据字段类型动态显示不同的运算符。你的 date 字段很可能没有被识别为时间类型（Time），而是被当成了字符串或数字。”

我点击transform选项卡里面的 debug 按钮，看到Input date，有如下信息：

输入的字段还是 字符串，而不是时间类型，无法做比较，最终也就无法筛选出指定数据；

正确方法演示 – 来自sonat

核心：Transformations 里面做好数据转化

步骤一、增加Convert field type（用于数据转化）

Filed选择 date ， 类型 as Time ， 输入格式 Input format 为 YYYY-MM-DD

这一步就将数据转化成时间类，让date具备筛选的条件；

步骤二、增加Filter data by values（用于筛选合适的数据）

  1. Filter type选择 Include
  2. Field 选择 date
  3. Match 选择 Is between
  4. Value 是 $__from and $__to
