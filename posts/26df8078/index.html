VCSA异常-vmdir状态为只读

Posted on 2026-10-01 In VMware , vSphere

故障现象

  1. vCenter Server 升级在 80% 处失败，报错：
  2. vCenter 未与其他 vCenter 配置 Enhanced Linked Mode（增强链接模式）；
  3. VMDir 状态变为只读（Read-only）：
  4. 所有服务都能正常启动；
  5. 检查复制时发现环境中存在一个不存在的服务器：

    正常应只列出 vcenter1.example.local；且 showpartners、showpartnerstatus 均无输出。

  6. vmafdvmdirclient.log 日志中有复制错误：

适用版本：VMware vCenter Server 7.x、8.x

原因分析

过去曾有一个 vCenter 或 PSC 从环境中移除，但未正确地从 vCenter 的 SSO 域中注销（unregister），残留的失效条目导致 VMDir 复制异常，进而使 VMDir 状态变为只读。

解决方法

⚠️ 警告：如果对错误的 vCenter 执行以下操作，会摧毁该 vCenter。操作前务必反复确认要移除的服务器确实已不存在。

1. 确认失效 vCenter 确实不存在

对要移除的主机名（如 vcenter2.example.local）进行 PING、nslookup，并在 vCenter 中按名称搜索，确认该主机已不在环境中。

2. 对 vCenter 做快照

对 vCenter 做关机状态下（powered off）的快照。若环境使用 Enhanced Linked Mode，需同时对所有关联的 vCenter 打快照。

3. 将 VMDir 状态设为 Normal
