VCSA证书替换工具-vCert

Posted on 2026-10-01 In VMware , vSphere

概述

vCert.py 是 Broadcom 官方推荐的 vCenter 证书管理工具（菜单驱动式），提供大多数证书相关操作的管理能力，用于在 vCenter Server 证书过期时实现无缝替换。它是已弃用的 fixcerts 脚本的替代工具。

适用版本：VMware vCenter Server 7.0.x、8.0.x、9.x
工具版本：vCert-6.1.2-20260713.zip

菜单选项详解

1. Check current certificates status（证书健康检查）

检查项包括：

  • 证书是否已过期
  • 证书是否将在 30 天内过期
  • Machine SSL 的 PNID 是否在 Subject Alternative Name（SAN）字段中
  • Key Usage 值是否受支持（Machine SSL 和 Solution Users）
  • 证书 SAN 字段是否为空（Machine SSL 和 Solution Users）
  • 是否使用推荐的 Key Usage 值（Machine SSL、Solution Users、STS 签名证书）
  • CA 证书是否缺少 Subject Key Identifier 扩展
  • 多个 CA 证书是否存在相同 Subject（VMware Directory 与 VECS TRUSTED_ROOTS 中的 CA）
  • 是否存在非 CA 证书混入 CA 存储（VMware Directory 与 VECS TRUSTED_ROOTS）
  • 证书链是否缺少 CA 证书
  • 证书是否使用非法 Alias（VECS TRUSTED_ROOTS）
  • 是否使用不支持的签名算法（md2WithRSAEncryption、md5WithRSAEncryption、RSASSA-PSS、dsaWithSHA1、ecdsa_with_SHA1、sha1WithRSAEncryption）
  • VECS 中 Solution User 的证书与 VMware Directory 中 Service Principal 条目是否匹配
  • 因父 CA 违反路径长度限制导致证书无效（Machine SSL、Solution Users、VMware Directory 与 VECS TRUSTED_ROOTS 中的 CA）

2. View Certificate Info（查看证书信息）

打印以下各类证书的人类可读信息：

  • 选项 1、2、6、9 显示证书的可读信息和指纹（fingerprint）
  • 选项 3、4、5、10、11 显示基本信息列表（Subject、Issuer、有效期、thumbprint 等），可选中后查看可读信息与 SHA1 指纹
  • 选项 7 显示各 vCenter 扩展应引用的 thumbprint 配置值
  • 选项 8 显示基本信息列表
  • 选项 10（Smart Card）在 vCenter Server 9.0 及以上不支持

3. Manage Certificates（管理证书）

  • 选项 1（Machine SSL）：替换 VECS 中的 Machine SSL 证书并更新当前节点的 SSL 信任锚点。可用 VMCA 签名证书或自定义 CA 签名证书。自定义 CA 时可选择生成私钥 + CSR，或导入已签名的证书和密钥；若提供的 CA 签名证书不含完整 CA 链，脚本会提示提供包含完整链的文件

    注：vCenter 8.0 U3h 起，VMCA 签发的 Machine SSL 证书到期前 5 天自动续期（前提：VMCA 证书模式为 vmca）

  • 选项 2（Solution User）：替换 VECS 中的 Solution User 证书，并更新 VMware Directory 中的 Service Principal 条目，同时更新 vCenter 数据库中的 vpxd-extension thumbprints。可用 VMCA 或自定义 CA 签名证书

  • 选项 3（VMware Directory 中的 CA）：打印 CA 信息，并提供子菜单发布或移除 VMware Directory 中的证书

  • 选项 4（VECS 中的 CA）：打印 VECS 中的 CA 信息，并提示删除一个或多个证书（CA 需先发布到 VMware Directory 才能加入 VECS TRUSTED_ROOTS）

  • 选项 5（SMS）：打印 VECS 中 SMS 存储的条目，包括 vmware-sps 服务使用的证书和需要信任的第三方 VASA provider 证书；子菜单可重新生成 SMS 自签名证书和 VMCA 签名证书

  • 选项 6（Data Encipherment）：替换 VECS 中的 Data Encipherment 证书和私钥

  • 选项 7（vCenter Extension thumbprints）：检查 vpx_ext 表中以下扩展的 thumbprint 是否不匹配：

    • com.vmware.vim.eam（vpxd-extension）
    • com.vmware.rbd（vpxd-extension，至 vCenter 8.0 U2）
    • com.vmware.vcIntegrity（vpxd-extension）
    • com.vmware.vlcm.client（vpxd-extension，vCenter 8.0 及以上）
    • com.vmware.imagebuilder（vpxd-extension，vCenter 7.0 和 8.0）
    • com.vmware.vsan.health（Machine SSL）
    • com.vmware.vmcam（Authentication Proxy）

    检测到不匹配时提示更新扩展 thumbprint。vCenter 9.0 中证书 PEM 会额外存储在扩展条目中

  • 选项 8（STS 签名证书）：备份当前 STS 签名证书和 CA 证书，删除 VMware Directory 中所有 TenantCredential 条目，然后创建带 VMCA 签名证书的新条目。若存在用户自定义 Scheduled Tasks，会告警：替换 STS 签名证书会使任务中存储的认证 token 失效，任务需删除后重建

  • 选项 9（VMCA）：替换 VMCA 证书并重新签发 Machine SSL、Solution User 和 STS 签名证书。可用 VMCA 或自定义 CA 签名证书；也可选择仅替换为自签名证书且不重新生成其他证书，灵活处理（详见 KB 438284）

  • 选项 10（Smart Card CA）：打印反向代理 Smart Card CA 过滤器文件和 VMware Directory 中 Smart Card 签发 CA 的列表，可添加/移除；vCenter 9.0 及以上不支持

  • 选项 11（LDAPS Identity Source）：打印为 AD over LDAPS Identity Sources（vCenter 7.0 为 ADFS）配置的证书列表，可添加或移除 LDAP 服务器证书

  • 选项 12：清理 VECS BACKUP_STORE（及 BACKUP_STORE_H5C，若存在）中的过期证书

  • 选项 13：清理 VECS 中 TRUSTED_ROOT_CRLS 存储的条目

  • 选项 14：清理 MACHINE_SSL_CERT 存储中的 __MACHINE_CSR 条目（通过 vSphere Client 生成 CSR 时创建，含对应私钥）

4. Manage SSL Trust Anchors（管理 SSL 信任锚点）

  • Check：输出 SSO 域内所有 vCenter 节点作为 Lookup Service 注册和当前 Machine SSL 证书使用的所有唯一 SSL 信任锚点证书信息，可同时显示对应的 Service ID 和 endpoint URI，展示每个服务注册/端点使用的是哪张证书
  • Update：更新 SSO 域内选定 vCenter Server 的 SSL 信任锚点。此方法直接修改条目，而非通过 Lookup Service 脚本或库实现

5. Check configurations（检查配置）

  • 选项 1（SSL 拦截检查）：尝试连接 hostupdate.vmware.com:443，比对返回证书的签发者是否为 DigiCert TLS RSA SHA256 2020 CA1。若签发者是其他实体，提示下载返回的 CA 证书并发布到 VMware Directory；若 CA 链不完整，提示需手动安装缺失的 CA 证书（之后可通过本选项安装）
  • 选项 2（STS 服务端证书和配置检查）：检查 STS 服务配置使用的是 MACHINE_SSL_CERT 存储（greenfield 6.x/7.x 部署）还是旧版 STS_INTERNAL_SSL_CERT 存储（从 5.5 升级的系统存在）。若配置了其他存储，提示更新配置并重启服务。同时检查 VMware Directory 的 vmwSTSConnectionStrings 属性：独立 vCenter 该值应指向本机 VMware Directory 实例（通过 vCenter 主机名），而 ELM（Enhanced Linked Mode）环境下应指向 localhost。值不正确时会提示更新
  • 选项 3（VECS 存储状态和权限检查）：检查 VECS 中默认存储的存在性和权限分配。缺失则提示重建，权限不符则提示重新分配；若当前 vCenter 版本找不到存储权限模板，提示创建（仅限 greenfield 全新部署）

6. Reset all certificates with VMCA-signed certificates（VMCA 重置所有证书）

用 VMCA 签名的证书重置以下证书：

  • Machine SSL（含 SSL Trust Anchors 和 vCenter 扩展 thumbprints）
  • Solution Users（含 vCenter 扩展 thumbprints）
  • STS Signing

7. ESXi certificate operations（ESXi 证书操作）

  • 选项 1：检查 VECS 中 TRUSTED_ROOTS 存储里反向代理（443 端口）和 IOFilter VASA provider（9080 端口）使用的证书签发者；同时检查 vCenter 的 Machine SSL 证书签发者，以及 /etc/vmware/ssl/castore.pem 文件中的 SMS 证书（SMS 证书也可能在 /etc/vmware/ssl/iofiltervp_castore.pem）
  • 选项 2：比对 ESXi 主机 443 端口提供的 SSL 证书与 vCenter 数据库中的信息。若不一致，可能导致 vSphere HA 或 vSAN 等服务出现问题
  • 选项 3：替换 ESXi 主机上的 /etc/vmware/ssl/rui.crt、/etc/vmware/ssl/rui.key 和 /etc/vmware/ssl/castore.pem 文件
    • 替换后需重启主机服务才能应用新证书和密钥
    • 需在 vCenter 中断开并重新连接主机，以更新 vCenter 数据库中的新证书信息

注：vCenter 8.0 U3h 起，VMCA 签发的 ESXi 证书到期前 5 天自动续期（前提：VMCA 证书模式为 vmca）。

8. Restart services（重启服务）

选项 2 输入的服务名会与 service-control --list 的输出列表进行比对。

9. Generate certificate report（生成证书报告）

生成的报告包含以下内容：

  • VECS 中的所有条目
  • VMware Directory 中的所有 CA 证书
  • VMware Directory 中的所有 Service Principals（Solution Users）
  • VMware Directory 中的所有 STS 签名证书条目
  • 文件系统上的各种服务证书（Authentication Proxy、VMware Directory 等）
  • Smart Card Authentication 的 CA 证书（vCenter Server 9.0 及以上不提供）
  • AD over LDAP(s) Identity Sources 的 CA 证书
  • Lookup Service 注册的 SSL 信任锚点

报告会打印到屏幕，并保存到 /var/log/vmware/vCert 目录下的文件中。
