Github仓库访问方式变更记录

Posted on 2026-11-22 In Linux

需求背景

Github 的仓库原本用的是 ssh key 通讯，我想试试改用 https 访问，不过在pull的时候账户与密码死活都连接不上。AI查询了一下后，发现要变更一下，改用Token访问。

原因分析

根本原因在于：GitHub 从 2021 年 8 月起就彻底禁用了密码认证，任何通过 HTTPS 推送代码的操作，密码字段都必须替换为个人访问令牌（Personal Access Token, PAT）。

相关通报： https://www.volcengine.com/article/249483

修改方式

第 1 步：创建 Personal Access Token (PAT)：

  1. 登录 GitHub，点击右上角头像 → Settings。
  2. 在左侧边栏最下方，点击 Developer settings。
  3. 选择 Personal access tokens → Tokens (classic)，然后点击 Generate new token (classic)。
  4. 给 Token 起个名字（如 hexo-deploy），务必在 Scopes 中勾选 repo 权限（如果是私有仓库，确保相关权限都选上）。
  5. 设置合适的过期时间，点击生成。
  6. 立即复制并妥善保存这个 Token，页面关闭后将无法再次查看。

注意Token有时效，也可以设置永不到期；

第 2 步：输入用户名与密码：

  1. Username：Github的账户名；
  2. Password：粘贴刚才的PAT；
