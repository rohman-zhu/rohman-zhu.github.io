vCSA5480服务提示异常-Services tab in VAMI shows warning message vCenter Server health is GREEN vc.health.error.dbjob2

Posted on 2026-10-01 In VMware , vSphere

故障现象

登录 vCenter 管理界面（VAMI，地址：https://[vCenter IP]:5480），在 Services（服务） 选项卡下，看到一条警告消息：

同时 vCenter Server 的健康状态（health）显示为 GREEN（绿色/正常），但警告依然存在。

适用版本：VMware vCenter Server 7.0.x、8.0.x

日志检查

原因分析

警告码 vc.health.error.dbjob2 的含义为：

数据库中的性能统计信息从”上周（Past Week）”到”上月（Past Month）”的汇总（rollup）未正常进行

即 vCenter 数据库（VCDB）中积累的历史数据（tasks、events、statistics）过多，导致按月（monthly）汇总统计任务（dbjob2）无法在计划时间内正常完成。

解决方法

1. 备份

⚠️ 操作前请务必对 VCSA 虚拟机做快照（Snapshot）；并且数据清理操作需征得客户同意后进行。

2. 清理数据库中的旧数据

删除 vCenter Server 数据库中旧的 tasks（任务）、events（事件）和 statistics（统计数据），参考 KB 313506《Delete old tasks, events and statistics data in vCenter Server 7.x and 8.x》中的脚本，将历史数据保留时间（retention）设置为自己期望的值。

脚本主要有三个参数（单位：天）：

  • TaskMaxAgeInDays：删除指定天数之前的 tasks
  • EventMaxAgeInDays：删除指定天数之前的 events
  • StatMaxAgeInDays：删除指定天数之前的 statistics
  • 取值说明：-1 = 不删除该类数据；0 = 删除全部；>1 = 只保留最近 N 天的数据
